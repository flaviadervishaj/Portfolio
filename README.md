# Flavia Dervishaj — Portfolio

Personal software development portfolio presenting selected full-stack and frontend projects, technical skills, education and professional background.

## Featured projects

- **BookEase** — appointment scheduling and service management with separate client and administrator workflows
- **Fitness Tracker** — authenticated workout logging, exercise discovery and progress history
- **ColdChat** — community messaging with private conversations, media and moderation
- **ClientFlow** — responsive client project management with browser persistence and portable backups

## Built with

- Semantic HTML5
- Modern CSS with responsive layouts and reduced-motion support
- Vanilla JavaScript
- No client-side framework or runtime dependency

## Run locally

```bash
npm install
npm run dev
```

The site can also be opened directly from `index.html`.

## Verification

```bash
npm test
npm run check
```

The test suite checks project links, page structure, local asset references and key accessibility attributes.
