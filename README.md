# Flavia Dervishaj — Portfolio

A responsive portfolio for my web development projects. Built with HTML, CSS, and JavaScript.

## Projects

- [BookEase](https://bookease-frontend.onrender.com/services) — service browsing and appointment booking; React, Flask, and PostgreSQL.
- [Fitness Tracker](https://fitness-tracker-two-phi.vercel.app/) — exercise guides and personal workout history; React, Flask, and PostgreSQL.
- [ClientFlow](https://client-flow-ten.vercel.app/) — client project tracking with account-based storage; React and Firebase.
- [ColdChat](https://coldchat.vercel.app/) — community chat and private conversations; JavaScript, Vercel, and Supabase. The source repository is private.
- Course Center — Odoo 17 module for course administration, enrollment, attendance and payments. Academic project; no public demo or source repository.

## Run locally

Open `index.html` in a browser, or run `npm install` and `npm run dev` to use the local development server.

The site uses Font Awesome icons and the Poppins font from their respective CDNs. The contact form opens the visitor's email application; the site does not store or send messages itself. Technical skills are listed by area without proficiency percentages.
